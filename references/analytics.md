# 数据分析与复盘

## 1. 原则

- 只比较同平台、同口径数据。
- 不使用未取到的数字估算。
- 样本小于 3 条时标“样本不足”。
- 分开看累计数据和单日增量。
- 先看漏斗，再看单条。
- 自动报告只做描述和线索发现，不能直接给出因果结论。人工可补充背景说明，但统一使用全量样本，不另行排除笔记。
- **统一全量口径**：所有已发布笔记共同进入累计、窗口增量和分组分析；不因手动发布、计划外、窗口外、系列例外或特殊时长设“隔离”标签或剔除。
- 实际发布时间、内容形式、主题和视频时长可作为描述性分组；样本不足 3 条标“样本不足”，不把组间差异写成因果结论。
- 发布窗口是否合规照常核对，但合规标记不影响笔记进入数据总量和分析。

## 2. 核心漏斗

```text
曝光
→ 观看
→ 2 秒/5 秒留存
→ 完播/阅读完成
→ 收藏/评论/分享
→ 主页访客
→ 关注
```

关键公式：

```text
封面点击率 = 观看 / 曝光
完播率 = 完整观看次数 / 观看次数
收藏率 = 收藏 / 观看
评论率 = 评论 / 观看
分享率 = 分享 / 观看
每百观看涨粉 = 涨粉 / 观看 × 100
主页访客率 = 主页访客 / 观看
```

不同平台对“观看”的定义可能不同。必须记录口径，不跨平台直接比较。

## 3. 14 个维度

1. **账号增长**：粉丝、净涨粉、主页访客
2. **流量规模**：曝光、观看、单条最高
3. **完播效率**：完播率、人均观看时长 ÷ 片长
4. **封面效率**：按封面方向分组
5. **互动质量**：点赞率、收藏率、分享率、评论数
6. **关注转化**：涨粉 ÷ 观看
7. **形式对比**：视频 vs 图文
8. **主题对比**：钱/权益、安全、家庭照护、窄人群等
9. **时长与钩子**：视频时长 × 完播，钩子类型
10. **流量来源与人群**：推荐、搜索、主页、关注页
11. **标题公式命中度**：S/A/B/C
12. **发布时段与标签**：窗口、标签、搜索占比
13. **开头类型**：缺口前置 vs 结论前置
14. **互动与转发归因**：认同、追问、反驳、分享

每个维度必须写：

```text
现状 → 目标 → 差距 → 动作 → 算法环节 → 验收指标
```

## 4. 24 小时与 72 小时

### 24 小时

看方向，不急着判死刑：

- 曝光是否足够
- 封面点击率是否达到基线
- 前 2 秒是否大量流失
- 收藏和评论是否出现
- 是否带来主页访客和关注

### 72 小时

决定是否做一次单变量调整：

- 曝光足够但点击率低：考虑改封面或标题
- 标题点击高但留存低：内容入口不一致或开头太慢
- 收藏高但评论低（自家内容）：缺少立场，或结尾没有给读者一个低门槛的表达入口；外联评论另按问句比例规则，不套用这一条
- 观看高但涨粉低：主页承接弱或内容人群不匹配

只改一个变量。不要同时改标题、封面、开头和发布时间。

## 5. 实验规则

- 一次只测一个变量。
- 每组至少 3–4 条内容，除非数据差异极大。
- 先记录基线，再实验。
- 不用一条内容的结果推翻全盘。
- 结果回写配置和选题池。

## 6. 报告纪律

自动脚本产出的时段、标题、形式等比较只作为全量样本的描述性观察，不直接认定“最佳”或因果。报告注明样本量和缺失字段；样本不足 3 条时不下比较结论。无需另建计划状态隔离表。

报告里不要出现：

- “感觉”“可能大概”
- 无来源数字
- 只写现象不写动作
- 把所有问题都归因于“内容不够好”
- 用累计数据冒充当天增量

必须写：

- 数据口径
- 缺失项
- 样本量
- 结论的证据
- 下一步动作和验收指标
