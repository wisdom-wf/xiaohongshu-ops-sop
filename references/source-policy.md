# 事实、来源、隐私与许可

## 1. 事实优先

金额、期限、资格、比例、法律条款和政策名称必须可核验。

- 能查到原文：写清来源和日期。
- 查不到：写“未核实”，不要写成确定结论。
- 平台笔记、网友评论、AI 输出都不能直接当官方来源。
- 过期政策必须标失效或重新核验。

## 2. 数字纪律

- 没有来源的数字不写。
- 百分比不能为了标题效果虚构。
- 修辞性百分比（“99% 的人都不知道”）不得伪装成统计结论。
- 政策数字必须区分全国口径、地方口径和时间口径。
- 改稿后检查数字是否丢失或被改动。

## 3. 引用和许可

- 不复制整本书、整篇付费资料或第三方课程。
- 引用观点时保留作者、出处和许可证。
- 不把第三方 PDF、课程、Skill 代码直接打包进公开仓库，除非许可证允许。
- 开源前检查引用的第三方技能、书籍、图片、字体、音乐和视频素材的许可。
- 示例账号数据必须脱敏。

## 4. 隐私

不要把以下内容提交到公开仓库：

- Cookie、Token、浏览器会话
- 手机号、微信号、邮箱、住址
- 账号密码和验证码
- 私人聊天截图
- 未脱敏的用户评论和个人主页链接
- 本地绝对路径中的个人目录信息

## 5. 对外发布

- 不承诺收益、政策资格或办理结果。
- 医疗、法律、金融内容必须写“以当地、当年、官方口径为准”。
- 不制造恐慌，不把个案写成普遍结论。
- 不诱导用户站外联系。
- 不把用户求助当作营销素材。

## 6. 版本治理

每次策略变化必须更新一个地方：

1. `xiaohongshu-ops.yaml`
2. 对应 reference 文件
3. 运行脚本的默认参数
4. 例行任务提示词

如果文档、配置和任务不一致，先停下审计，不要继续按旧规则运行。
