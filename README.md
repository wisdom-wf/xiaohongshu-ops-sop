# xiaohongshu-ops-sop · 小红书运营助手

![封面](listing/封面.jpg)

把一套真实跑通过的小红书运营流程装进你的 AI 助手：从选选题、写标题、做图审稿，到排期发布、回评论、看数据，每一步都有人带着走、有机器把关。

> 新手做小红书，最难的从来不是「发一条笔记」，而是不知道发什么、不知道为什么没人看、不知道下一步改哪里。这个技能把实战账号跑出来的完整运营方法整理成了流程，你只管做内容，规矩它来守，坑它替你踩过了。

## 亮点：封面这一关，它比你还较真

在小红书，用户只看到一块豆腐干大的缩略图，半秒内决定点不点。封面决定点击，点击决定平台还推不推你。这个技能把封面从「凭感觉做图」变成一条有标准、有检查的生产线：

1. **先写句子，再做设计**：封面承诺必须先写成一句完整的话（谁 + 什么情况 + 能做什么 + 数字/结果），禁止「大抽象词 + 小字解释」。
2. **一卡一件事**：每张卡片只承担一个信息点。
3. **可读性是硬指标**：关键文字 ≥38px、辅助 ≥30px、出处 ≥26px，对比度达标。
4. **先缩小再检查**：生成 270px 手机缩略预览 + 整套联系表，3 秒读不清就退回重做，不接受「有设计感」当理由。
5. **机器把关**：复核逐项记录，发布前工具核对，任何一项没过直接拦下。
6. **数字必须兑现**：封面写「3 笔钱」，第 2 页必须列出 3 笔独立的钱，机器会数。

**风格统一又不重复**：同一篇笔记内标题位置、字号层级、编号、页脚全统一，像一套模板；笔记之间配色、版式、字体刻意轮换，连续 3 条不重复同一视觉组合——读者记得住你的号，又不会审美疲劳。

## 覆盖环节

- **选题与排期**：内容支柱、选题颗粒度、标题 S/A/B 公式
- **内容生产**：视频脚本结构（缺口钩子/立场/出处）、图文卡片（一卡一点、首图完整承诺）
- **质检硬门**：图文视觉负向规则 V01–V10、事实与合规检查
- **发布排期**：每日发布位上限、窗口随机、排期锁、发布后回读核验、网页端发布实测坑清单
- **数据复盘**：14 维诊断、24h/72h 检查点、缺失数据口径红线
- **评论区服务**：作者首评、2 小时回复、回复绑定核验
- **双池外联**：同主题 15 + 爆款 15 计划上限、评论情绪模型、问句比例、冷却与限流、关注回扫、风控停止条件
- **付费生成预算门禁**：先授权、再预算、后记账（R1–R8）

## 安装

**方式一：千问（QwenWork）技能平台**
下载 [`listing/xiaohongshu-ops-sop.skill`](listing/xiaohongshu-ops-sop.skill)，在 QwenWork 中打开即可安装。

**方式二：手动安装**
把本仓库（除 `listing/` 外）放入你的技能目录，例如 `~/.qwenwork/skills/xiaohongshu-ops-sop/`。

## 快速开始

```bash
# 1. 初始化账号工作区
python3 scripts/init_workspace.py /path/to/workspace --account-name "你的账号名"
# 2. 编辑工作区里的 xiaohongshu-ops.yaml，替换所有 __占位符__
# 3. 校验配置
python3 scripts/doctor.py --config /path/to/workspace/xiaohongshu-ops.yaml
# 4. 跑一遍自测（21 项）
python3 -m unittest discover -s tests -v
```

之后对 AI 助手说「今天发什么」「这条能不能发」「帮我复盘」就行，详细流程从 [`SKILL.md`](SKILL.md) 读起。

## 特点与安全边界

- 所有数字参数（发布窗口、互动上限、评论字数、目标值）集中在一份配置文件，按账号调整，不写死。
- 浏览器执行层不绑定工具：任何浏览器适配器（Playwright MCP、Chrome 扩展 MCP 等）均可。
- 依赖仅 Python 3.10+ 与 PyYAML，其余脚本零第三方依赖。
- 默认人工触发（manual-only）：不自动创建定时任务；发布、评论、关注、私信、付费生成均需当次明确授权。
- 不绕过验证码与风控；Cookie/Token/个人数据不进仓库。
